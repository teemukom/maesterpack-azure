# Security

Report suspected vulnerabilities in this pack through [GitHub private vulnerability reporting](https://github.com/teemukom/maesterpack-azure/security/advisories/new). Do not report security vulnerabilities in public issues.

For vulnerabilities in Maester itself, use the [Maester security advisories](https://github.com/maester365/maester/security/advisories/new).

For non-security bugs or test findings, open a [pack issue](https://github.com/teemukom/maesterpack-azure/issues).
